# 6IX Chocolate Co.

Ordering site for 6IX Chocolate Co. (Lewisville, TX). Built by Omoniyi Studio.

- Vite + React, deployed on Netlify from `main`.
- Menu and prices: `src/data/menu.js`.
- The gift box is CSS and SVG only (`src/components/GiftBox.jsx`, styles in `src/index.css`).
